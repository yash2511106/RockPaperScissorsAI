# 🤖 Rock Paper Scissors AI Game (Teachable Machine + Scratch)

This is an AI-powered **Rock Paper Scissors** game built using **Google's Teachable Machine** and **MIT Raise Playground (Scratch)**.

## 🎮 How It Works

- The model was trained using **Teachable Machine** with custom image samples for:
  - ✊ Rock
  - 🖐️ Paper
  - ✌️ Scissors
- The trained model was imported into a Scratch-based project using **MIT Raise/Playground**.
- The webcam captures your hand gesture in real-time and the AI classifies your move.
- The Scratch code then generates a random move for the computer and compares the results to decide the winner.

## 📁 Files Included

- `rock-paper-scissors.sb3` — The complete Scratch project file with AI integration.

## 🚀 How to Run

1. Open the [MIT Raise Playground](https://play.raisely.app) or [MIT Scratch 3.0](https://scratch.mit.edu).
2. Upload the `.sb3` file.
3. Allow camera access.
4. Play the game using your hand gestures!

## 🧠 Tech Stack

- [Google Teachable Machine](https://teachablemachine.withgoogle.com/) — for training the image classification model.
- [MIT Raise Playground](https://play.raisely.app) — to build the AI-powered Scratch project.
- Scratch 3.0 — block-based programming platform.

## 📸 Training Classes Used

- Rock (fist)
- Paper (open hand)
- Scissors (two fingers)
